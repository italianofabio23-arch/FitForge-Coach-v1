# FitForge Coach V1

MVP Flutter dell'app fitness/nutrizione FitForge Coach.

## Funzioni già incluse
- Profilo: nome, sesso, età, peso, altezza, lavoro/attività, obiettivo e giorni di allenamento.
- Calcolo BMR, mantenimento, deficit/surplus e macro.
- Obiettivi: dimagrire, definizione, massa muscolare, rassodare, benessere/tonicità.
- Piano palestra 3/4/5 giorni con serie, ripetizioni e recuperi.
- Mini workout a casa.
- Dieta settimanale variata con grammature scalate sul target calorico.
- Pasto libero controllato.
- Ricette cliccabili/sezione dedicata.
- Consigli base sugli integratori.
- Tracker calorie giornaliere (MVP).
- Check-in del peso (MVP).
- Profilo salvato localmente con shared_preferences.
- Branding/logo FitForge Coach incluso in assets/images.

## Avvio
Se hai Flutter installato:
1. Apri un terminale nella cartella del progetto.
2. Se mancano le cartelle piattaforma Android/iOS/Web, esegui: `flutter create .`
3. Esegui: `flutter pub get`
4. Esegui: `flutter run`

## Nota prodotto
Questa V1 è una base funzionante. Prima della vendita vanno aggiunti backend/account, storico persistente completo, onboarding sanitario e privacy, acquisti/in-app purchase, notifiche, analytics, test, contenuti professionali e revisione legale/nutrizionale.

FitForge Coach è pensata come app fitness/wellness per adulti e non sostituisce pareri medici o dietetici professionali.
